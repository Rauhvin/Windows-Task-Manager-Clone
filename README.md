# Task-Manager-viaWindows
A Windows Task Manager clone built with WPF and .NET 8

## Features
- Real-time CPU Monitoring: Track processor load using system performance counters.
- RAM Usage Tracking: Dynamic calculation of used memory relative to total physical RAM.
- Live Charts: Smooth data visualization using LiveCharts2 (SkiaSharp).
- MVVM Architecture: Clean separation of logic and view for better maintainability.

## Tech Stack
- C# / .NET 8
- WPF (Windows Presentation Foundation)
- LiveChartsCore.SkiaSharpView.WPF
- CommunityToolkit.Mvvm
